# Disease Prediction System

Machine Learning based disease prediction web application.

## Features

- Disease Prediction using Random Forest
- React Frontend
- Node.js Backend
- Python ML Model
- Symptom Selection
- Confidence Score
- Disease Information
- PDF Report Download
- Prediction History

## Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- Python
- Scikit-Learn
- Random Forest
